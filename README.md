# 🚀 Collaborative NLP Platform – Full-Stack Web App  

A **full-stack platform** for researchers and developers in **Arabic NLP**, featuring **research paper sharing, AI-powered recommendations, and collaboration tools**.  

## 🛠️ Tech Stack  
- **Frontend:** React.js  
- **Backend:** Express.js (Node.js)  
- **Database:** PostgreSQL  
- **AI/ML:** Python (Recommendation System)  
- **Architecture:** Microservices  

## ✨ Features  
✅ Research paper sharing & collaboration  
✅ AI-powered recommendation system  
✅ User authentication & role-based access  
✅ Secure REST API with JWT authentication  
✅ PostgreSQL for structured data storage
